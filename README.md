# Ремонтная мастерская — Kanban-доска заявок

Учебный проект по приёму и отслеживанию заявок на ремонт техники реализованной  в ввиде Kanban-доски.

## Установка и запуск

```bash and cmd
cd repair_kanban
python -m venv .venv (python3 -m venv .venv)

# Windows:
.venv\Scripts\activate

# Linux/macOS:
source .venv/bin/activate


pip install -r requirements.txt

# Фронтенд (Основной способ способ запуска)
python main_ui.py
# http://127.0.0.1:8080


# Или только API
python main.py
# http://127.0.0.1:8000/docs

#После запуска через main_ui.py вам понадобиться админ,для возможности все поверить и создать пользователей новых с ролью master
admin:
login:клерик
password:676767

```
## Настройка Supabase

В `.env` указан `DATABASE_URL` к проекту Supabase (PostgresSQL).  
Таблицы создаются автоматически при первом запуске (`Base.metadata.create_all`).

Возможно файл .env может исчезнуть или отсутствовать.В этом случае,пожалуйста создайте файл с именем .env возле файлов main_ui.py и main.py и скопируйте туда следующий код:

DATABASE_URL=postgresql+psycopg2://postgres.tpuafmkveszjuobihkjp:my_secret_12345@aws-1-eu-west-1.pooler.supabase.com:5432/postgres
JWT_SECRET=my_secret_12345


(Если при присутствии данного файла с данной информацией все равно терминал продолжает писать ошибку связанный с sqlalchemy или что то подобное:# NOQA: E501 , то пожалуйста свяжитесь со мной в ТГ :@OneClode,я вышлю вам обновленные свежие ключи так как supobase требуетих обновления для корректной связи с проектом)

## Примечание по таблицам

Проект использует собственные таблицы SQLAlchemy (`users`, `projects`, `boards`, `columns`, `cards`, `comments`, `history`).  
Они совместимы с Postgres в Supabase.



## Стек

- **Frontend**: NiceGUI (Python)
- **Backend API** (опционально): FastAPI
- **БД**: PostgreSQL через Supabase
- **Auth**: JWT + bcrypt (роли: client / master / admin)

## Роли

| Роль     | Возможности                                      |
|----------|--------------------------------------------------|
| client   | Просмотр своих заявок, создание (через доску)    |
| master   | Работа с назначенными заявками, смена статуса    |
| admin    | Всё + создание досок, управление                 |

## Статусы заявки (колонки)

1. **Принята**
2. **Диагностика**
3. **В ремонте**
4. **Готова к выдаче**
5. **Выдана**

Карточка = заявка на ремонт (название устройства, описание неисправности, метки типа устройства, приоритет, назначенный мастер).


## Что умеет

- Регистрация / вход с ролями (клиент, мастер, админ)
- Список досок + создание (admin/master)
- Kanban-доска:
  - Колонки = статусы ремонта
  - Цветные метки (Смартфон, Ноутбук, Экран…)
  - Карточки-заявки: описание, приоритет, исполнитель, дедлайн, метки
  - Комментарии
  - Перемещение карточек между статусами (drag / меню)
  - Поиск и фильтры
  - Добавление своих колонок (при необходимости)

## Быстрый старт для демонстрации

1. Войти в аккаунт пользователя с ролью **admin**.
2. Создайте доску новую или используйте готовые
3. Добавьте заявки (карточки) в колонку «Принята».
4. Перетаскивайте / перемещайте по статусам.
5. Зарегистрируйте  нового мастера

## Как запускать Юнит тесты

1. Перейти в скрытую папку .venv
2. Выполнить команду:pip install pytest
3. Далее вернуться в корень прокета repair_kanban  с помощью команды: cd ..
4. Выполните команду:pytest tests/ -v
